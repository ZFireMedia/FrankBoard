## Self-Serve Support Section

**Start here.** Most questions can be answered without contacting us.

- **Documentation** — [Getting started](#), [deployment guide](#), [migration from Kanboard](#). We also link to Kanboard docs for app behavior.
- **GitHub** — [Open an issue](https://github.com/ZFireMedia/FrankBoard/issues) for bugs or feature requests. [Discussions](https://github.com/ZFireMedia/FrankBoard/discussions) for questions.
- **Troubleshooting** — Common setup issues (DB connection, permissions), plugin compatibility notes. Can't find it? Open an issue.

---

## Community Support Section

**Community edition users**

Support for Community is best-effort. We don't have an SLA for Community users — we respond when we can, and the community helps when it can.

- **GitHub issues** — Bug reports, feature requests
- **GitHub discussions** — Questions, tips, sharing
- **Documentation** — Always available

We don't pressure Community users to upgrade for basic help. If you're stuck, check the docs and GitHub first. If you need guaranteed response times, that's what Pro is for.

## Pro Support Section

**Pro subscribers** *(when Pro is available)*

Pro includes priority email support and a defined response-time SLA. Same product as Community, plus commercial use rights and assurance that someone will respond.

- Priority email support
- Response-time SLA
- Commercial license
- Same self-hosted deployment

## Services Section

**Need help beyond self-serve?**

We offer project-based assistance:

- **Migration assistance** — Moving from Kanboard or another tool to FrankBoard. We'll help with backup, config, and verification.
- **Deployment setup** — VPS setup, Docker config, reverse proxy. Get up and running without the guesswork.
- **Training** — Team onboarding, admin training. Per-session or fixed fee.

Contact us with your needs. We'll provide a scope and quote.
