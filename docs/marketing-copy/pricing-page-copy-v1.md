## FAQ Section

**Is Community really free?**  
Yes. All core features. Self-hosted. No time limit. No credit card. No bait-and-switch.

**What does Pro include?**  
Commercial use license, priority support, and a defined response-time SLA. Same feature set as Community. Pro is for teams that need assurance and formal licensing.

**When will Pro and Cloud be available?**  
We're building capacity. Pro will come first (manual licensing, then automated). Cloud follows once we have managed infra in place. Contact us to join the waitlist or express interest.

**Can I migrate from Kanboard?**  
Yes. Same database schema. Backup your data, point FrankBoard at your DB, verify. Reversible. See our [migration guide](#).

**Do you offer trials?**  
Community is the trial. Run it, use it, evaluate it. Pro and Cloud trials will be available when those editions launch.

**What happens if I outgrow Community?**  
Upgrade to Pro for commercial use and support. No feature lock-in — Community has all the same core features. You're upgrading for license and support, not for features.

**Is there a free Cloud tier?**  
Possibly in the future (e.g., 1–2 users for evaluation). Not committed yet. We'll update when we have details.

**Also available: migration and deployment assistance**  
Need help moving from Kanboard or setting up FrankBoard on your VPS? We offer project-based assistance. [Contact us](#) for details.
