## Short (2–3 sentences)

FrankBoard is a modernized work board for small teams. Built on Kanboard — same database schema, plugin API, and migration paths — with a cleaner UI and Docker-first deployment. Community edition is free and fully functional; Pro and Cloud add support and managed hosting when you need them.

## Hacker News (Show HN)

**Title**: Show HN: FrankBoard — a modernized Kanboard for small teams

**Body** (adapt as needed):

```
I ran Kanboard for years and always wished for a cleaner UI and simpler deployment. FrankBoard is a fork that keeps what Kanboard got right — boards, tasks, swimlanes, plugins — and polishes the experience.

- Docker + PostgreSQL out of the box
- Same schema and plugin API; migration from Kanboard is a config swap
- Community free; Pro/Cloud when you need support or managed hosting
- No Jira creep — we keep it simple

Site: https://frankboard.com
GitHub: https://github.com/ZFireMedia/FrankBoard

Open to feedback.
```
