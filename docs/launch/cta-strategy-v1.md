# FrankBoard CTA Strategy v1

**Date**: 2025-03-16  
**Scope**: First CTA priority for soft launch.

---

## Primary CTA: Get Community Free → GitHub

**Placement**: Hero, nav, footer across frankboard.com  
**Destination**: https://github.com/ZFireMedia/FrankBoard  
**Goal**: Drive visitors to the repo — clone, star, open issues.

**Why this first**:
- Lowest friction. No signup, no email capture.
- GitHub is the canonical distribution point for Community.
- Stars and activity are measurable signals.
- Aligns with "try before you buy" — Community is the trial.

## Soft Launch CTA Focus

For Phase 1, optimize for:
1. **Get Community Free** — Ensure the GitHub link is correct, visible, and unambiguous.
2. **Contact us** — Ensure mailto works and inbox is monitored. Pro/Cloud waitlist interest.

Do not add new CTAs in Phase 1. Simplify, don't expand.

---

## Copy Notes

- "Get Community Free" — Clear, low commitment.
- Avoid "Sign up" or "Register" — we don't have that; it's GitHub.
- "Try Community" — Alternative if "Get" feels heavy.
