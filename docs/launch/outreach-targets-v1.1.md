# FrankBoard Outreach Targets v1.1

**Date**: 2025-03-16  
**Scope**: Refinement — outreach channel order emphasizes direct/personal first, HN later.

---

## Outreach Channel Order

Execute in this order. Do not skip to HN or Reddit before personal outreach.

| Order | Channel | Action | Rationale |
|-------|---------|--------|-----------|
| **1** | Direct / personal outreach | Email, LinkedIn, DMs to known Kanboard users, ops leads, folks who wanted simpler boards | Highest signal. One-on-one, qualified. Learn from real conversations. |
| **2** | Kanboard / self-hosted spaces | Kanboard GitHub discussions, Kanboard forum, DevOps/self-hosted Discord/Slack | Directly relevant. Migration CTA resonates. Respectful, contextual. |
| **3** | Reddit | r/selfhosted, r/kanboard (if active) | Broader reach. Still niche. Post once; don't repost. |
| **4** | Hacker News | Show HN | Defer until ready. Higher visibility, higher scrutiny. Use after learning from 1–3. |

| Why | Where |
|-----|-------|

## Channel Execution Notes

### 1. Direct / Personal (First)

- Identify 10–20 people: ran Kanboard, asked about simpler boards, ops decision-makers.
- Email or LinkedIn. Use personal outreach template (see announcement-copy-v1.1).
- Lead with migration: "If you're on Kanboard, migration is straightforward. Happy to walk you through it or help with setup."
- Track responses. Log what resonated.

### 2. Kanboard / Self-Hosted Spaces (Second)

- Kanboard GitHub: Respect their norms. Fork notice, or helpful comment in relevant discussion. Don't spam.
- Kanboard forum: Same. Add value. Link to migrate page when migration is the topic.
- Discord/Slack: Join, lurk, contribute. When migration/setup comes up, share FrankBoard with context.

### 3. Reddit (Third)

- r/selfhosted: One post. Context: "Modernized Kanboard, migration path clear. Built for teams that want simpler boards."
- Link to frankboard.com. Migrate page prominent in copy.
- Don't repost. Wait for feedback.

### 4. Hacker News (Later)

- Post Show HN when you have early signal (migration interest, setup requests) and are ready for broader visibility.
- Higher volume, higher scrutiny. Use learnings from 1–3 to refine message.

---

## Channel Rules

1. **Order matters** — Personal first. HN last.
2. **Be useful** — Don't spam. Add context. Migration and setup are the hooks.
3. **Respect Kanboard** — We're a fork, not a replacement. No bashing.
4. **One post per channel** — Don't repost. Wait, learn, then revisit.
5. **Link to frankboard.com** — Migrate page is primary landing for migration CTA.
