# FrankBoard Homepage Messaging v1

**Date**: 2025-03-15  
**Status**: Strategy document  
**Scope**: Launch-facing homepage structure; documentation only, no implementation.

---

## Homepage Goal

Convey in 10–15 seconds that FrankBoard is a **modern, self-hosted work board for small teams** — simple to run, straightforward to use. Build trust and direct visitors to the right next step (try Community, compare editions, or migrate from Kanboard).

---

## Target Audience

| Primary | Secondary |
|---------|-----------|
| Small teams (2–10) looking for a simple work board | Kanboard users evaluating a modernized alternative |
| Ops leads and technical founders | Privacy-conscious orgs needing self-hosted |
| Teams tired of Jira/Asana complexity | Solopreneurs managing multiple projects |

---

## Hero Options

| Option | Copy | Tone |
|--------|------|------|
| A | **A modern work board for small teams.** Simple to run. Straightforward to use. | Direct, confident |
| B | **Your boards. Your data. No bloat.** A Kanboard-based work board, modernized for small teams. | Control, compatibility |
| C | **Work boards that stay simple.** Self-hosted, Docker-ready, Kanboard-compatible. | Utility, trust |
| D | **A cleaner work board for teams that prefer control.** Built on Kanboard. Modernized for today. | Evolution, respect |

**Recommendation**: A or C for broad appeal; B or D when Kanboard audience is primary.

---

## Subhead Options

| Option | Copy |
|--------|------|
| 1 | Boards, tasks, swimlanes. No enterprise complexity. Self-host with Docker in minutes. |
| 2 | Modernized UI. Same Kanboard core. Your data, your infrastructure. |
| 3 | Run it yourself or let us host it. Community free. Pro and Cloud when you need support. |

**Recommendation**: 1 or 2 for hero; 3 if editions are prominent above the fold.

---

## Core Benefit Blocks

| Block | Headline | Supporting copy |
|-------|----------|-----------------|
| **Simple** | Keeps boards simple | Boards, tasks, columns, swimlanes. No custom fields or workflow engines. |
| **Modern UI** | Polished, not plain | Typography, spacing, light/dark themes. Cleaner than stock Kanboard. |
| **Self-hosted** | Your data, your control | Docker + PostgreSQL. Deploy on your VPS. No vendor lock-in. |
| **Compatible** | Built on Kanboard | Same schema, plugin API, and migration paths. Move in — or back — with a backup. |

---

## Trust Blocks

| Block | Content |
|-------|---------|
| **Data ownership** | "Your data stays where you put it. Export anytime." |
| **Open foundation** | "Built on Kanboard. Plugin ecosystem preserved." |
| **No bait-and-switch** | "Community edition is fully functional. Core features stay free." |
| **Reversible** | "Migration from Kanboard is straightforward. So is moving back." |

---

## CTA Recommendations

| CTA | Placement | Target |
|-----|-----------|--------|
| **Get Community** | Hero, footer | Download / Docker / GitHub |
| **Compare editions** | Below hero, mid-page | Pro/Cloud prospects |
| **Migrate from Kanboard** | Mid-page, footer | Existing Kanboard users |
| **See pricing** | Near trust blocks | Paid-intent visitors |

Primary hero CTA: **"Get Community Free"** or **"Try Community"** — low friction, no signup.

---

## Page Section Order

1. **Hero** — Headline, subhead, primary CTA
2. **Benefits** — 4 blocks (Simple, Modern UI, Self-hosted, Compatible)
3. **Editions teaser** — One-line per edition; link to comparison
4. **Trust** — Data ownership, open foundation, no bait-and-switch
5. **Migration** — Short block for Kanboard users; link to migration page
6. **Footer CTAs** — Get Community, Compare editions, Migration, Pricing

---

## Notes

- Avoid AI, automation, or "smart" language
- Keep enterprise terms (SSO, audit, SLA) out of hero/benefits
- Match actual product: no claims about features not shipped
