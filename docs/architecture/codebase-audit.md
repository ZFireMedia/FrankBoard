## 2. Entry Points and Bootstrap

### Web Entry

- **`index.php`** → `app/common.php` → router dispatch  
- **`healthcheck.php`** → `app/common.php` → `SELECT 1` → JSON `{"status":200,"message":"Database connection is OK"}`

### Bootstrap Order (`app/common.php` / `app/bootstrap.php`)

1. **PicoDb UrlParser** — If `DATABASE_URL` env var is set, parses it and defines `DB_DRIVER`, `DB_USERNAME`, `DB_PASSWORD`, `DB_HOSTNAME`, `DB_PORT`, `DB_NAME`. Takes precedence over config files.
2. **Config files** (in order):
   - `data/config.php` (if exists) — preferred for instance overrides
   - `config.php` (if exists) — root config
3. **`app/constants.php`** — Defines fallbacks for all constants from env vars (`defined() or define()`)
4. **`app/check_setup.php`** — Validates PHP version, PDO extensions, writable dirs, REVERSE_PROXY_AUTH + TRUSTED_PROXY_NETWORKS

### Config Precedence

1. `DATABASE_URL` (env) — overrides DB_* entirely when set
2. `data/config.php` — overrides constants
3. `config.php` — overrides constants
4. `constants.php` — env var fallbacks, then hardcoded defaults

## 3. Database Layer

- **ORM**: PicoDb (minimal PDO wrapper in `libs/picodb/`)
- **Drivers**: sqlite, mysql, postgres, odbc, dblib, mssql
- **Schema**: `app/Schema/Postgres.php`, `Mysql.php`, `Sqlite.php`, `Mssql.php`
- **SQL definitions**: `app/Schema/Sql/postgres.sql`, `mysql.sql`
- **Migrations**: `app/Schema/Migration.php` — versioned schema; `DB_RUN_MIGRATIONS` controls auto-run on startup

### PostgreSQL Notes

- Full support via `pdo_pgsql`
- Schema version stored in `schema_version` table
- `DatabaseProvider::runMigrations()` runs on each request when `DB_RUN_MIGRATIONS` is true
- Do not run migrations from multiple processes concurrently

## 4. Docker Integration

### Image Layout (Official Kanboard Image)

- **Base**: Alpine 3.23
- **Stack**: Nginx, PHP 8.4-FPM, s6 overlay
- **App path**: `/var/www/app`
- **Data/plugins**: `/var/www/app/data`, `/var/www/app/plugins` — must be writable by nginx
- **SSL**: `/etc/nginx/ssl` — self-signed cert generated by entrypoint if missing

### Environment Passthrough

`docker/etc/php84/php-fpm.d/env.conf` forwards env vars to PHP-FPM. Key vars:

- `DATABASE_URL` — primary DB config (format: `postgres://user:pass@host:port/dbname`)
- `API_AUTHENTICATION_TOKEN`, `PLUGIN_INSTALLER`, `DEBUG`, `LOG_DRIVER`, etc.

### Entrypoint (`docker/entrypoint.sh`)

1. Generate self-signed SSL if `/etc/nginx/ssl/kanboard.key` and `.crt` missing
2. `chown -R nginx:nginx` on `/var/www/app/data` and `plugins`
3. Start s6-svscan (manages nginx + php-fpm)

## 8. Findings for FrankBoard

- **Minimal changes needed**: Config via env vars; no code changes for VPS Docker deployment
- **DATABASE_URL** is the primary mechanism for Docker; avoids config file for DB credentials
- **Reverse proxy**: When running behind nginx/Caddy, set `TRUSTED_PROXY_NETWORKS` and `TRUSTED_PROXY_HEADERS` if using `REVERSE_PROXY_AUTH`
- **Migrations**: Run automatically on first request; ensure only one process migrates
- **Healthcheck**: `/healthcheck.php` is suitable for Docker/K8s health probes
