Support when you need it.

We want you to succeed. Self-serve options come first. Paid support is available for teams that need assurance.

Start here

Most questions can be answered without contacting us.

  • Documentation — Getting started, deployment guide, migration from Kanboard. We also link to Kanboard docs for app behavior.
  • GitHub — Open an issue for bugs or feature requests. Discussions for questions.
  • Troubleshooting — Common setup issues (DB connection, permissions), plugin compatibility notes. Can't find it? Open an issue.

Community edition users

Support for Community is best-effort. We don't have an SLA for Community users — we respond when we can, and the community helps when it can.

  • GitHub issues — Bug reports, feature requests
  • GitHub discussions — Questions, tips, sharing
  • Documentation — Always available

We don't pressure Community users to upgrade for basic help. If you're stuck, check the docs and GitHub first. If you need guaranteed response times, that's what Pro is for.

When Pro is available
