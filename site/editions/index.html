FrankBoard offers three ways to run: Community (free, self-hosted), Pro (paid, self-hosted, with support), and Cloud (managed by us). All editions share the same core features. The difference is how you run it and what support you get.

For individuals, small teams, and evaluation. Free, full-featured, self-hosted. No time limit, no feature gates.

FAQ

Can I move from Community to Pro?

Yes. Same deployment, same data. You add a Pro license and support. No migration required.

What's included in Cloud?

Managed hosting, backups, upgrades, and support. You sign up; we run it.

Are core features different between editions?

No. Boards, tasks, swimlanes, and plugins work the same. Pro and Cloud add license, support, and (for Cloud) hosting.

Can I try before paying?

Community is the trial. Run it free. When you need Pro or Cloud, contact us.
