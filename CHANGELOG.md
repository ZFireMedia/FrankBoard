# Changelog

All notable FrankBoard releases are documented here.

## [frankboard-1.1.0] — 2026-10-06

First tagged FrankBoard product release (`frankboard-1.1.0`). Tag name avoids colliding with upstream Kanboard’s historic `v1.1.0`.

### Added

- Modernized UI (login, board, task cards/detail, modals, forms, dashboard; Waves 1–4)
- VPS-first Docker + PostgreSQL deployment defaults
- Marketing site (frankboard.com) with migrate, pricing, and screenshots
- Product differences document vs upstream Kanboard
- Soft-launch packaging: Community free; paid migration/setup assistance

### Upstream

- Based on Kanboard v1.2.51
- Same database schema and plugin API target — see [differences-from-kanboard.md](docs/product/differences-from-kanboard.md)
